棒球進階數據指標與計算公式指南
打擊指標 (Batting Metrics)
指標 全稱 計算公式 說明
AVG Batting Average (打擊率) H / AB 安打數除以打數，最基礎的安打產出能力。
OBP On-Base Percentage (上壘率) (H + BB + HBP) / (AB + BB + HBP + SF) 衡量打者避免出局、成功站上壘包的比率。
SLG Slugging Percentage (長打率) Total Bases / AB 衡量打者每次打數能推進壘包的能力（一壘打x1+二壘打x2+三壘打x3+全壘打x4）。
OPS On-Base Plus Slugging (攻擊指數) OBP + SLG 綜合上壘與長打破壞力的綜合進攻指標，.800 以上屬優秀水準。
ISO Isolated Power (純長打率) SLG - AVG 剔除一壘安打水分，純粹衡量擊出長打的原始爆發力。
BABIP Batting Average on Balls In Play (H - HR) / (AB - K - HR + SF) 場內擊球形成安打的機率，常搭配運氣與擊球品質分析。
BIP% Balls In Play Percentage (AB - K) / PA 球打進場內的比率，衡量擊球接觸品質。
SO/BB Strikeout to Walk Ratio SO / BB 三振與四壞球比，越低代表選球本領越頂尖。
投球指標 (Pitching Metrics)
指標 全稱 計算公式 說明
ERA Earned Run Average (自責分率/防禦率) (ER * 9) / IP 投手平均每九局所失掉的自責分，越低越優。
WHIP Walks plus Hits per IP (BB + H) / IP 每局被上壘率，衡量投手壓制打者上壘的穩定度，1.20 以下為優秀。
K/9 Strikeouts per 9 Innings (SO * 9) / IP 每九局平均三振次數，衡量投手的奪三振壓制能力。
BB/9 Walks per 9 Innings (BB * 9) / IP 每九局平均保送次數，衡量投手的控球準確度。
H/9 Hits per 9 Innings (H * 9) / IP 每九局被擊出安打率。
HR/9 Home Runs per 9 Innings (HR * 9) / IP 每九局被擊出全壘打率。
